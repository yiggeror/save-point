# 《存档点》 音乐与声音

看：`film/save-point-1080p.mp4`（正片声轨）、`film/save-point-review-1080p.mp4`（对照版，右侧显示当前音乐 cue 和小节.拍）。
听：`music/theme-demo.m4a`（主题小样，完整一遍）。段落表：[`cue-sheet.md`](cue-sheet.md)。

## 一首曲子贯穿全片

- **商店 BGM**：F 大调，120 bpm，4/4，八分音符摇摆（swing）。
- **编制**（16 位游戏的小乐队）：长笛主旋律 + 高八度的钟琴、马林巴打反拍、拨弦和低音提琴打一三拍、竖琴、沙锤和木鱼。
  采样来自 FluidR3 GM，再按每件乐器加一道柔和的低通（像音源芯片的插值），全部过同一个短的反馈回声（像 SNES 的 echo），
  所以听起来是同一个游戏世界里的声音。
- **曲式**：A（8 小节，停在 C 上，**开放**）· A′（8 小节，回到 F，**收束**）· B（桥段）· A″。
- **钩子**：C–F–A（和"存档完成"的三个音同一个上行琶音），回答 G–F–D。

**核心设计：直到勇者回来之前，这首曲子一次都没能走到收束。**每一轮都从第一小节开始，走到 A′ 的一半就被窗外的"游戏结束"打断；
第一次听到 A′ 收在 F 上，是柜台底下画上那颗星的时候。

## 所有有音高的音效都在 F 大调上

门铃 F6 · 金币 C7/A6/F7 · 菜单 C6→F6 · 读地图每一行一个上行的 F 大调音 · 碰撞格子的弹簧 F4→C5 · 边界碎开 F 五声音阶 · 存档 C–F–A–C。

## 响度

整片 -16.5 LUFS。各段响度见段落表：商店 BGM 约 -17.3 到 -17.9，蒙太奇 -16.2（全片最响，只比开头响约 1.5 LU，靠密度和速度而不是音量），
八音盒 -21.8，等待 -23.7（段内渐强），回来 -17.7，字幕 -16.7。段落表同时自动检查每段的起止和重叠：现在**没有任何两段重叠**，每段都在下一段开始前收干净。

## 说明

- **我听不到声音。**旋律、和声、节奏是按乐理写的，编好后用频谱图、逐乐器响度和整段响度去检查（音符是否落在拍子上、各声部是否平衡、段落是否重叠），
  但好不好听、记不记得住，需要你用耳朵判断。旋律哪里不喜欢可以直接说（比如"钩子不够抓耳""太像儿歌""想要更暖/更俏皮"），我改。
- 游戏里的声音（门铃、金币、菜单、边界、存档、碰撞格子、读档）是合成的，都在 F 大调上；屋子里的真实声音（脚步、门、长凳、衣料、钱袋、倒茶、喝茶、茶杯、纸、盾）
  是 CC0 录音（`production/audio/foley.py`，来源见 [`CREDITS.md`](../CREDITS.md)），勇者的脚步重、店主的轻。
- 采样音色是 FluidR3 GM，每件乐器一道低通、共用一个短回声，没有换别的音色库。

## 片头

单独的 6 秒片头（`production/audio/title.py`），两条声轨：**配乐版**是八音盒和竖琴弹钩子 C–F–A、回答 G–F–D，收在存档完成的三个音上；
**音效版**只有声音：存档图标的滴答、片名一行一行加载、"Save Point"逐字打出、芯片音色的"存档完成"。
